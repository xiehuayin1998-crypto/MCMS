
# 会议室申请管理权限分配指南

## 权限说明

会议室申请管理功能需要 `APPLICATION_MANAGEMENT_VIEW` 权限。用户需要拥有此权限才能：

- 查看会议室申请管理页面
- 审批待处理的申请
- 拒绝不符合要求的申请
- 撤销已通过的申请

## 分配权限的两种方式

### 方式一：通过角色分配（推荐）

#### 步骤1：创建或编辑角色
1. 进入 **权限管理系统** 页面
2. 在 **角色管理** 标签页中：
   - 点击"新建角色"创建新角色
   - 或选择现有角色点击编辑按钮

#### 步骤2：分配申请管理权限
在角色编辑对话框中：
1. 找到 **申请管理** 权限组
2. 勾选以下权限：
   - `application.management.view` - 查看申请管理
   - `application.management.approve` - 审批申请
   - `application.management.reject` - 拒绝申请
   - `application.management.cancel` - 撤销申请

#### 步骤3：为用户分配角色
1. 切换到 **用户权限分配** 标签页
2. 找到需要授权的用户
3. 点击"分配角色"按钮
4. 勾选刚刚配置好的角色

### 方式二：直接为用户分配权限

#### 步骤1：编辑用户权限
1. 在 **用户权限分配** 标签页找到目标用户
2. 为用户分配包含申请管理权限的角色

## 权限验证

用户获得权限后，可以通过以下路径访问会议室申请管理：

1. 点击首页导航栏的 **个人工作台**
2. 切换到 **会议室申请管理** 标签页
3. 点击 **进入会议室申请管理** 按钮

## 注意事项

1. **权限继承**：用户权限通过角色继承，一个用户可以拥有多个角色
2. **管理员权限**：管理员用户自动拥有所有权限
3. **权限优先级**：直接权限 > 角色权限 > 默认权限
4. **权限缓存**：权限变更后可能需要重新登录才能生效

## 常见问题

**Q：用户看不到会议室申请管理入口怎么办？**
A：检查用户是否拥有 `APPLICATION_MANAGEMENT_VIEW` 权限

**Q：用户能看到入口但无法审批申请怎么办？**
A：检查是否分配了 `application.management.approve` 权限

**Q：权限分配后多久生效？**
A：通常立即生效，如未生效请尝试重新登录
